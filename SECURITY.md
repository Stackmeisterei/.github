# Security Policy

## Reporting a vulnerability

Please **do not** report security issues in public issues, pull requests or chats.

Report them privately to the HAFN Solution Team:

- E-mail: **elden.sokoli@hafn-it.de**
- Or contact the repository owners directly (see `CODEOWNERS`).

Please include:

- What is affected (repository, file, environment)
- Steps to reproduce or a proof of concept
- The possible impact

## What happens next

- We confirm receipt within **2 working days**.
- We assess the issue and tell you the next steps within **5 working days**.
- We keep you updated until the issue is fixed.

## Leaked secrets

If you find a secret (password, key, token) in this repository:

1. Report it right away using the contact above.
2. Do not use or share it.
3. The owner revokes and rotates it. Removing it from the code alone is not enough.

## Supported versions

Only the latest version on the default branch receives security fixes.
